## Files (folder `src`, one package per exercise)
| Package | Files | Content |
|---|---|---|
| ex1 | Rectangle.java, Main.java | Exercise 1 – Rectangle (no-argument and parameterized constructors, area, perimeter) |
| ex2 | Fraction.java, Main.java | Exercise 2 – Fraction (copy constructor, simplify, +, −, ×, ÷) |
| ex3 | Time.java, Main.java | Exercise 3 – Time (validation, add/subtract seconds with 24-hour wrap-around) |
| ex4 | Circle.java, Main.java | Exercise 4 – Circle (area, perimeter, point inside/on the circle) |
| ex5 | Dice.java, Main.java | Exercise 5 – Dice (roll n times, frequency and experimental probability) |
| ex6 | Calculator.java, Main.java | Exercise 6 – Calculator (method overloading) |

## How to run
1. Install JDK 11 or later and Visual Studio Code with the Extension Pack for Java.
2. Open this folder in VS Code.
3. Open `src/exN/Main.java` and click **Run** above `main()`.
4. Exercise 5 asks for the number of rolls `n` in the Terminal.
